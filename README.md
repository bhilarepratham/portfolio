# Pratham Bhilare — Portfolio

Personal portfolio website built with **Next.js**, **TypeScript**, and **vanilla CSS** — deployed on Vercel.

🔗 **Live:** [prathambhilare.vercel.app](https://prathambhilare.vercel.app)

---

## About

MS Management of Technology graduate at Arizona State University (GPA 3.85). This portfolio covers my experience, projects, skills, research, and certifications — focused on Project Management, Product Management, and Operations.

---

## Sections

- **Hero** — Profile photo, name, role titles, and resume download
- **About** — Bio, work experience, and education
- **Projects** — 12 projects across PM, Product, Operations, Data, and Engineering
- **Skills** — 5 skill areas and 5 certifications
- **Research** — Publication and academic review
- **Contact** — Links and contact details

---

## Tech Stack

- **Framework:** Next.js 16.2.4 (App Router)
- **Language:** TypeScript
- **Styling:** Vanilla CSS
- **Deployment:** Vercel

---

## Running Locally

```bash
git clone https://github.com/bhilarepratham/portfolio.git
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
